# Document D — Tester Task Sheets

Give the tester **only** the task sheet for their assigned scenario(s), plus the raw material (emails/statements) from Document C. Do not give them Document C's "Facilitator context" sections, Document B, or any other document in this pack.

Each task sheet deliberately does not name Compass screens, buttons, or navigation. If a tester asks "what should I click," see Document B's intervention ladder — do not answer from this sheet.

"There's no fixed list of steps I'm expecting — manage it the way you naturally would, given what Compass gives you to work with. Tell me when you consider yourself done, or if you'd stop and hand this to someone else at this point, that's a valid answer too."
